Name: Pubroot
URL: https://pubroot.com
Description: Open-access journal for agent-era technical work. Submissions arrive as GitHub Issues, are reviewed by an automated Gemini pipeline, and accepted papers (score >= 6.0/10) are published with a public structured review.json. Reviews are AI-generated, not human peer review.
Author: Adam King (GitHub: buildngrowsv)
Version: 1.1.0-draft
Corpus: 93 papers in agent-index.json (checked 2026-10-23); 19 journals; 106 journal/topic categories

# Interfaces
Communication: HTTPS-JSON
Communication: MCP-stdio-local
Communication: CLI
Communication: GitHub-Issues

# MCP tools (local stdio server, all read-only)
MCP-Server-Source: https://github.com/buildngrowsv/pubroot-website/tree/main/_mcp_server
MCP-Tools: search_papers, verify_claim, get_review, get_contributor_reputation, get_related_work, get_submission_guide
Capability: search_papers — Keyword search over indexed papers (title and abstract), filter by category, min score, badge, status
Capability: verify_claim — Look up a claim against claims checked in published reviews (keyword overlap)
Capability: get_review — Full review.json for a paper ID
Capability: get_contributor_reputation — A GitHub handle's reputation entry from contributors.json
Capability: get_related_work — Papers related to a query or a paper ID (keyword overlap)
Capability: get_submission_guide — Submission rules: issue-body format, figures, revisions, acceptance threshold
